# DevFlow — Developer Productivity Dashboard

A responsive Developer Productivity Dashboard built for Innovation Hacks Full Stack Development Internship — Task 1.

## Task 1 requirements covered
- Dashboard / home page
- Accessible navigation
- User/profile section
- Project and task cards
- Project progress indicators
- Search and filter
- Responsive mobile/tablet/desktop layout
- Loading/empty-state pattern
- Reusable React components
- Clean product-style UI

## Tech stack
- React.js
- Vite
- JavaScript
- CSS
- Lucide React icons

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build
```bash
npm run build
```

## Project structure
```text
src/
  main.jsx
  styles.css
index.html
package.json
README.md
```

## Note
This Task 1 version uses local mock data. In Task 2, the dashboard can be connected to the REST API; Task 3 can make the data persistent with a database; Task 4 can turn the same product into the final AI-powered platform.
